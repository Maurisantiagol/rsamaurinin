# rsamaurinin

Ejercicio viejo de Java (2021) del algoritmo RSA, con dos ventanas Swing: un lado cliente y un lado servidor.

## Qué contiene

- `RSAMAURININ/src/rsamaurinin/ladoCliente.java` y `ladoServidor.java` (con sus formularios `.form`).
- Proyecto de NetBeans (`nbproject/`, `build.xml`, `manifest.mf`).

## Estado

Proyecto escolar antiguo y sin terminar; no hay instrucciones de uso en el código.

## Cómo abrirlo

Abre la carpeta `RSAMAURININ` como proyecto en NetBeans y ejecuta la clase principal.
